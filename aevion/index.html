                            🧩 Plugins
                            
    
                            
      
                            Plug in an app or a site you already use
                            
      
                            Everywhere Aevion has taken you — a search, a pick from its own directory, a link you opened — is listed here, because Aevion is the one that opened it. 🔌 Plug in turns one into a plugin with the search box already turned into {query}, so “youtube lofi beats” works from then on, no address typing and no setup.
                            
      
                              
      
                              Apps on this device. In the Android app Aevion can read the real list of installed apps and start one by name. A browser tab cannot — no browser exposes the installed-program list — so here Aevion asks you for the address instead, and says as much rather than failing silently.
                              
      
                              
      
                              
      
                                
    
                                

    
                                
      
                                Add a plugin — no code
                                
      
                                Give it a trigger and a reply and it works immediately, in this chat, stored on this device. Placeholders: {query} is whatever you typed after the trigger, {name}, {time}, {date}, {lang}. A reply template cannot read files or reach the network — which is exactly why adding one is safe.
                                
      
                                App & site plugins. Add an https link and the plugin becomes an action instead of an answer: it opens that address through the same confirm-tier “open a link” tool as the rest of the app, so it opens nothing you have not approved, every single time. Put {query} in the link to search with what you type (e.g. https://duckduckgo.com/?q={query}), and an optional second link that is tried if the first fails. What a web page cannot do is list the apps installed on your device or read your browser history — no browser exposes either — so nothing here pretends to: the plugin holds the address you give it.

                                  Privacy & Permissions
                                  
      
                                  
      
                                  
      
                                  On by default: Aevion answers from the online brain while the internet is there, drops to the offline brain by itself when it is not — or when the endpoint stops answering — and switches back by itself a minute later, without a message to dismiss or a switch to flip. The header pill always says which brain is answering (LOCAL · OFFLINE AI · ONLINE AI). Turn it off and it always tries the online brain first and tells you plainly when it cannot.
                                  
      
                                  
      
                                  
      
                                  Device access
                                  
      
                                  
      
                                  
      
                                  
        
        
      
                                  
      
                                  This asks for every permission this device can actually give — in one go, one at a time, and it shows you exactly which were granted and which were refused. It is a shortcut for the rows below, not a bypass: a tool still needs its own permission, and anything irreversible (posting, deleting, opening a link, sending your data anywhere) still asks you every single time. Nothing here is silent, and Revoke all takes it back instantly.

                                    Self-upgrade 
                                    
      
                                    With this on, Aevion can install a knowledge pack you approve — new words for the offline brain, a data-driven plugin, or facts waiting for your approval. It can never install code into itself: a pack that claims to carry code is refused, and the files in aevion/ remain the only way its own code changes. Turning this on needs your explicit approval, and turning it off needs nothing — safety is always allowed.
                                    
      
                                    
      
                                    
      
      
                                    
        
        
      
                                    
      
                                    
      
                                      
    
                                      

    
                                      
      
                                      App updates 
                                      
      
                                      This is how Aevion stays current — the same way any app on your phone does: it checks whether a newer signed build exists, and, if it does, the user approves the install. When that happens the existing app is replaced in place and your chats, memory, settings, keys and everything else stay put — nothing is wiped.
                                      
      
                                      
      
                                      
      
                                      
      
                                      On a web tab there is no install — a browser tab cannot replace an installed app, so the tab only checks and reports what it finds. On the Aevion Android app the app downloads the signed APK and asks the system to replace the old one (after you approve the system dialog). Every install still runs through the same self-upgrade consent gate and the same per-install confirmation — there is no silent update, ever.
                                      
      
                                      A newer build can only be installed if it is signed by the same key that signed the version already on the device. That is what keeps a hijacked download URL from sneaking up on you — the app verifies the downloaded file against the published checksum before it even offers the install.
                                      
    
                                      

    
                                      
      
                                      AI provider
                                      
      
                                      
      
                                      
      
                                      
      
                                      
      
                                      
      
      
                                      
      
                                      
      
                                      
      
                                      
      
                                      That button asks every brain this device can reach — a server on your own machine, the in-browser model, a hosted key you already saved — and switches to the best one that answers. It never overrules a choice that already works, and it never sends a prompt to find out — only “are you there?”.
                                      
      
                                      
      
                                      
      
                                      Each provider keeps its own endpoint, model and key, so switching back and forth never loses your setup. Fallback only ever happens within the same trust class: a failing cloud provider can drop to the on-device model, but your prompt is never silently rerouted to a different company.
                                      
    
                                      

    
                                      
      
                                      More than one brain 
                                      
      
                                      Every provider above keeps its own key, so you can add as many as you like — nine of them are free to start. Tick the ones to use together and pick what “together” means. Nothing here is a claim that models merge into something smarter; each strategy does something specific and honest.
                                      
      
                                      
      
                                        
      
                                        
      
                                        Each leg of a multi-brain message is a separate call and shows up in Tools → 🧠 Brain log with its own latency, so you can see exactly what was asked and what came back. A brain that fails is skipped and named, never silently swapped for another company.
                                        
    
                                        

    
                                        
      
                                        In-browser AI (WebLLM · WebGPU)

After that the model runs fully offline on your GPU — nothing you type is ever sent anywhere.

                                        🎤 Voice
                                        
    
                                        Aevion can talk and listen. Both stay off by default, so the microphone is never opened without your say-so.
                                        

    
                                        
      
                                        Hands-free by name 
                                        
      
                                        
      
                                        Whatever you type here is what Aevion answers to — the tab title and the HUD show it, and it is what the mic listens for: say «Hey Aevion …» and it starts. Same setting as “Assistant name” in Settings, yours to change any time.
                                        
      
                                        
        
      
                                        
      
                                        
        
        
      
                                        
      
                                        Say its name and ask in one breath — «Hey Aevion, what is 2+2», «Hayy Aevion tell me a joke», «Yo Aevion open youtube» — and the request runs straight away. Say just the name (or a greeting plus the name) and it answers with a cue, then takes your next sentence as the request. After a reply you can keep talking without repeating the name, and talking over it stops it mid-sentence. Nicknames work too: type one in the box above and it answers to that one instead.
                                        
      
                                        
      
                                        This mode keeps the microphone open, so it is off by default: it stops itself after a few idle minutes and pauses whenever the page is hidden. That is a battery and privacy decision, not a limitation.
                                        
    
                                        

    
                                        
      
                                        Text-to-speech 
                                        
      
      
                                        
      
                                        
      
                                        
      
                                        
      
      
                                        
      
                                        
      
                                        
      
                                        A voice here is a named combination of speed, pitch and — where your device offers a choice — which of its own voices to use. Your device decides the timbre; Aevion only ever asks it for a different speed or pitch. Moving the sliders by hand keeps the voice name and marks it as adjusted, so nothing is ever silently overridden.
                                        
    
                                        

    
                                        
      
                                        Speech input
                                        
      
                                        
      
                                        
      
                                        
    
                                        

    
                                        
      
                                        Live speak & translate
                                        
      
                                        Speak in one language and Aevion says it back in another, out loud, phrase by phrase — for a conversation across a language you do not speak. Listening uses your device's speech engine, so the microphone stays open only while this is on; translation uses your browser's online service, so “Allow online search” has to be on in Settings.
                                        
      
                                        
        
        
      
                                        
      
                                        
      
                                        
    
                                        

    
                                        
      
                                        Teach a command 
                                        
      
                                        The offline brain already answers in every language listed in Settings, using the words people actually say. If a word you use is missing, add it here — it is stored on this device and matched from the next message on. This is also how a language with no table yet starts working: teach it “time”, “joke”, “note”… one word at a time.
